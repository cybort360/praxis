Praxis

Privacy Policy

Last updated: May 2026

Short version: Praxis has no servers and no accounts. Your API key and session history live only on your device. The only data that ever leaves your browser is the video transcript, sent directly to the AI provider you configure.

What Praxis does not do

  • Praxis does not have a backend server
  • Praxis does not collect analytics or usage data
  • Praxis does not create or require an account
  • Praxis does not sell, share, or transmit your data to any party other than the AI provider you explicitly configure

Data stored on your device

Praxis uses chrome.storage.local and chrome.storage.session — both of which store data locally in your browser, never on a remote server.

Data Where stored Purpose
API key chrome.storage.local Authenticate requests to your chosen AI provider
Provider and model choice chrome.storage.local Remember your settings between sessions
Session history chrome.storage.local Display past sessions, streaks, and summaries in the History tab (max 50 entries)
Active session state chrome.storage.session Restore the side panel if the browser reloads mid-session; cleared when the session ends

You can delete all history at any time using the Clear History button in the History tab.

Data sent over the network

When you start a learning session, Praxis sends the following to your AI provider:

  • The video transcript (text only — no audio or video)
  • The video title

This data is sent directly from your browser to the AI provider's API using your own API key. Praxis is not an intermediary — the request goes straight from your device to the provider.

When you use the tutor chat, your questions and the session summary are sent to the AI provider. Raw transcript data is not resent on every chat message — only the compact AI-generated summary is included.

Third-party AI providers

Praxis supports multiple AI providers. Each provider has their own privacy policy governing how they handle data sent to their API:

  • Anthropic (Claude)
  • OpenAI (GPT)
  • Google (Gemini)
  • Groq
  • OpenRouter

You are responsible for reviewing the privacy policy of the provider you choose to use with Praxis.

Permissions

Praxis requests the following Chrome permissions:

Permission Why it's needed
sidePanel Display the Praxis panel alongside the video
storage Save your API key and session history locally
scripting Read the video player state on YouTube to extract the transcript
activeTab Access the current tab when you explicitly interact with the extension

Code execution

The coding challenge runs user-written code in an isolated <iframe> sandbox (JavaScript) or via the Piston API (all other languages). The Piston API is a third-party service — code submitted for execution is sent to emkc.org. No identifying information is included in these requests.

Children's privacy

Praxis is not directed at children under 13. We do not knowingly collect information from children.

Changes to this policy

If this policy changes materially, the "Last updated" date at the top of this page will be updated. Continued use of the extension after changes constitutes acceptance of the revised policy.
